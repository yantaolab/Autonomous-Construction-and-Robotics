# Contributing

## Acknowledgement

We gratefully acknowledge **Dr. Xinyu Chen** for his valuable support and contribution to the development of the course website for **Autonomous Construction and Robotics**.

## Adding course materials

You are welcome to contribute course-related materials, including project code, tutorials, reading resources, datasets, and useful external links. Please place material in the relevant project or library folder and include a short `README.md` where helpful.

Before contributing, please make sure that you do not upload private student work, personal data, passwords, API keys, or other sensitive information.
