# Purpose
Use a real-world housing sales dataset from King County, Washington, to build an interpretable baseline model, enhance model performance through feature engineering, compare two predictive models, and analyze the sources of prediction error within a 60-minute time limit.

# Files description
**DISC5105 Week2 A1 Assignment Questions.docx**: The description of assignment  requirements and the template of the answer sheet.
**DISC5105_Week2_Housing_Price_Tutorial.ipynb**: The tutorial materials, in-class activities, and demonstration code used in the session.
**DISC5105_Week2_Housing_Price_Tutorial.pptx**: Tutorial slides covering fundamental concepts, the dataset description, and guidance on setting up the computing environment.
**DISC5105_Week2_Housing_Price_kc_house_data.csv**: The dataset used for the demonstration code.
