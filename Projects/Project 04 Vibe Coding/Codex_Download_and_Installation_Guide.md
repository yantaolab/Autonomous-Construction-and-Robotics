# Codex Download and Installation Guide

Official download page: https://learn.chatgpt.com/docs/app  (Windows);https://openai.com/codex/  (Mac)

## Windows

1. Open the official download page and select the Windows version or the corresponding store link.
2. If you are directed to the Microsoft Store, click **Get** or **Install**. If you download an installer, double-click it and follow the instructions to complete the installation.
3. After installation, open the app from the Start menu and switch to Codex.

## macOS

1. Open the official download page and select the macOS version. Confirm that your Mac meets the operating system and chip requirements listed on the page.
2. Open the downloaded installation file. If it is a `.dmg` file, drag the app into the **Applications** folder. For other file formats, follow the installation instructions.
3. Open the app from the **Applications** folder and switch to Codex.
