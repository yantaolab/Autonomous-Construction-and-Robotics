## Create a new project

Click **Add file → Create new file** in the `projects` folder and name it, for example:

```text
projects/project-01/README.md
```

GitHub creates the folder automatically. You can then upload all files for that project into the same folder.

> Do not upload personal data, private student work, passwords or API keys. For a file larger than 100 MB, use Google Drive, Zenodo, Hugging Face or GitHub Releases and add its URL in the Links page.
