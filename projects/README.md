
# Projects

Put each course project in one folder. A project can contain anything you need: a PDF, Python/MATLAB code, Jupyter/Colab notebook, data sample, image or a short `README.md`.

## Create one with GitHub

1. Click **Add file → Create new file**.
2. Enter a path such as `project-01/README.md`.
3. Click **Commit new file**.
4. Open the new folder and use **Add file → Upload files**.

Example:

```text
projects/
└── project-01/
    ├── README.md
    ├── tutorial.pdf
    ├── code.py
    └── notebook.ipynb
```
